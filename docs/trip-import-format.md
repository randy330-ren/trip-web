# 旅程資料 JSON 格式與 AI 提示詞

把行程檔（Excel、Word、PPT、PDF、文字）連同下面的「提示詞」一起丟給 AI，AI 會產出一份 JSON。
再到網站：**建立新旅程**的「旅程 JSON」欄位，或既有旅程的 **管理設定 → 匯入旅程資料** 貼上即可。

## 重要限制

- 目前只匯入「文字行程」：每天的日期、標題、路線、餐食、出發前提醒、天氣地點。**地圖釘子、住宿卡、連結請匯入後在網頁上手動新增。**
- 日期必須由前到後排列，**不支援跨年**的旅程。
- `week`（星期）不用填，網站會依日期自動算出。
- 最多 31 天。過長的文字會被自動截斷。
- 傳給 AI 前，請先刪掉護照號碼、訂位代號、信用卡、電話等個資。

## 格式

```json
{
  "pageTitle": "2027 沖繩自由行",
  "title": "沖繩・春日紀行",
  "subtitle": "那霸 ｜ 2027.03.10 - 03.12",
  "eyebrow": "2027 JAPAN / OKINAWA",
  "shortName": "沖繩",
  "year": 2027,
  "splash": {
    "from": "TPE",
    "to": "OKA",
    "eyebrow": "2027 JAPAN / OKINAWA",
    "title": "沖繩・春日紀行"
  },
  "map": {
    "center": [
      26.2124,
      127.6809
    ],
    "zoom": 10,
    "farKm": 150,
    "region": "沖繩地區"
  },
  "weather": {
    "places": {
      "naha": [
        "那霸",
        26.2124,
        127.6809
      ],
      "motobu": [
        "本部",
        26.6577,
        127.8985
      ]
    }
  },
  "notes": [
    "3/10 抵達後先到飯店寄放行李。",
    "3/12 退房後前往機場。"
  ],
  "days": [
    {
      "month": 3,
      "day": 10,
      "tag": "抵達・市區",
      "title": "抵達那霸・國際通散步",

      ],
      "foodLabel": "那霸",
      "wx": "naha",
      "steps": [
        "08:40 桃園出發",
        "12:30 抵達那霸機場",
        "搭單軌電車前往飯店",
        "國際通散步"
      ]
    },
    {
      "month": 3,
      "day": 11,
      "tag": "海洋・景點",
      "title": "美麗海水族館",
      "meals": [
        "飯店早餐",
        "備瀨福木並木道午餐",

      "steps": [
        "自駕前往本部",
        "美麗海水族館",
        "備瀨福木並木道"
      ]
    }
  ]

```

| 欄位 | 必填 | 說明 |
|---|---|---|
| `pageTitle` | ✅ | 旅程名稱（瀏覽器分頁與「我的旅程」清單使用）|
| `title` / `subtitle` / `eyebrow` | | 頁面頂部的大標題、副標題、小字 |
| `shortName` | | 簡稱（最多 10 字）|
| `year` | | 西元年，沒填用今年 |
| `splash` | | 開啟畫面的文字，`from`／`to` 是機場代碼 |
| `map` | | 地圖預設中心 `[緯度, 經度]`、縮放 `zoom`（1～18）、`farKm`（超過此距離新增地點時會提醒）、`region`（地區名稱）。沒填則用第一個天氣地點 |
| `weather.places` | | 天氣地點：`"代碼": ["名稱", 緯度, 經度]`，最多 12 個，代碼只能用英數、底線、連字號 |
| `notes` | | 出發前提醒，最多 20 則 |
| `days` | ✅ | 每天一筆，依日期由前到後 |
| `days[].month` / `day` | ✅ | 月、日（數字）|
| `days[].title` | | 當天標題，沒填顯示「第 N 天」|
| `days[].tag` | | 日期小卡上的短標籤，例如「抵達・市區」|
| `days[].note` | | 當天的貼心提醒（選填）|
| `days[].meals` | | `[早餐, 午餐, 晚餐]`，沒有的留空字串 |
| `days[].foodLabel` | | 餐食頁卡片上的地點名稱 |
| `days[].wx` | | 當天天氣使用的地點代碼，必須出現在 `weather.places` |
| `days[].steps` | | 當天路線，每個字串一個項目 |

## 給 AI 的提示詞（整段複製）

> App 內「建立新旅程」與「匯入旅程資料」視窗也有「📋 複製提示詞」按鈕，內容和下面相同。

> 請把我提供的旅遊行程整理成一份 JSON，只輸出 JSON 本身（不要加說明文字或程式碼框）。
> 格式與欄位如下：pageTitle、title、subtitle、eyebrow、shortName、year、splash（from、to、eyebrow、title）、map（center 為 [緯度, 經度]、zoom、farKm、region）、weather.places（每個地點為 "代碼": ["名稱", 緯度, 經度]，代碼用英文小寫）、notes（出發前提醒字串陣列）、days（陣列）。
> days 每一天包含：month、day（數字）、tag（8 字內短標籤）、title（當天主題）、note（可省略）、meals（[早餐, 午餐, 晚餐] 三個字串，未知填「待確認」）、foodLabel（地點名稱）、wx（天氣地點代碼，必須存在於 weather.places）、steps（當天路線，每個項目一個字串，保留時間與重點）。
> 規則：日期依先後排列、不可跨年；不要輸出 week；經緯度請給大致正確的數字；沒有資訊的欄位請省略，不要編造；請勿輸出任何個人資料。
